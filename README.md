# AgroConnect Frontend

This is the React frontend for the AgroConnect supply chain app.

## Features
- JWT authentication
- Routing
- Material UI styling
- CRUD pages for Users, Harvests, Demands, Orders

## Setup
1. Run `npm install` to install dependencies.
2. Run `npm start` to launch the development server.

## Folder Structure
- `src/components/` - Reusable UI components
- `src/pages/` - Main pages (Login, Dashboard, CRUD)
- `src/api/` - Axios config and API helpers

## Backend Integration
Update `src/api/axiosConfig.js` with your backend URL.
